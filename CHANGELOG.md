## [1.0.1] — 2026-10-16

### Fixed
- Исправлено наложение заголовка главного экрана («Выбери игру») на верхнюю иконку кругового меню — заголовок и кольцо вынесены в отдельные строки Grid.
- Исправлено сохранение избранного: `UserService.SaveCurrentUser` теперь корректно сохраняет список `FavoriteGames` в `users.json` (добавлена ветка для случая, когда пользователь не найден в списке).
- Исправлено отображение игр во вкладке "Избранное", полностью переписан `FavoritesView.xaml.cs`.

### Added
- Новый экран «Все игры»: полный список модулей с иконкой, названием и описанием.
  - Кнопка «Играть ▶» — быстрый запуск.
  - Звёздочка ⭐ — добавление/удаление из избранного прямо из списка.
  - Фильтр «Только избранные».
  - Сортировка: «Сначала избранные» / «По названию» / «По количеству игр».

## [1.0.0] — 2026-09-17

### Added
- Круговое анимированное меню игр на главном экране.
- Авторизация: регистрация, вход, выход.
- Избранные игры (звёздочка на кольце + отдельный экран).
- Рекорды с вкладками по играм и сортировкой.
- Профиль: аватар, смена логина, смена пароля, статистика.
- Встроенный музыкальный плеер (mp3/wav, shuffle, mute, громкость).
- Встроенная документация (9 разделов).
- Две темы: тёмная (тёплая красно-пурпурная) и светлая (аква + индиго).
- Plugin-система: встроенные модули + внешние DLL из `%AppData%\gamelibrary4\plugins\`.
- Игры:
  - 💣 Сапёр (10×10, 15 мин, авто-раскрытие, флажки).
  - 🐍 Змейка (ускорение, пауза, победа на полном поле).
  - 🔢 2048 (4×4, победа при 2048, проигрыш без ходов).
  - 🧩 Судоку (3 уровня сложности, генератор с проверкой единственности).
  - 🎯 Виселица (русский алфавит, 6 жизней, слова + подсказки).
  - ❌ Крестики-нолики (локально + по локальной сети через TCP:55555).
- Сетевая игра: хост + гость по LAN.
- Иконка приложения (в exe, окне, панели задач).
- Сохранение настроек, темы, громкости между запусками.

### Known limitations
- Плагины не могут записывать рекорды (TD-03).
- Пароли хранятся как SHA-256 без соли (TD-01).
- Сетевой режим работает только в пределах локальной сети.
- Судоку «Сложный» может генерироваться до 2 секунд.
