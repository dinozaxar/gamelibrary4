# gamelibrary4

Десктопная платформа казуальных игр на WPF (.NET 8).

## Возможности
- 🎮 Круговое меню игр
- 🧩 Встроенные игры: Сапёр, Змейка, 2048, Судоку, Виселица, Крестики-нолики
- 🏆 Рекорды с сортировкой и фильтрацией
- ⭐ Избранное
- 👤 Профиль с аватаркой
- 🎵 Встроенный музыкальный плеер
- 🌐 Сетевая игра по локальной сети
- 🧩 Plugin-система (внешние игры в DLL)
- 🎨 Тёмная и светлая темы

## Стек
- .NET 8.0 (WPF)
- C#
- TCP/JSON для сетевой игры

## Запуск
1. Открой `gamelibrary4.sln` в Visual Studio 2022.
2. `Ctrl+Shift+B` — сборка.
3. `F5` — запуск.
